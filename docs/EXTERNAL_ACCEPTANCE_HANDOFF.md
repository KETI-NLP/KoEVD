[실제 설정·명령](OAUTH_SUBMISSION_GUIDE.md)을 따라 등록 callback과 맞춘다.

운영자 자료는 `generated/full-operator-review-preparation-20261009-v56/README.md`와
같은 폴더의 모델별 준비본에 있다. 코드가 검토자 이름·권리 근거·승인을 대신
작성하지 않는다. [생성 영수증](GENERATION_RECEIPT_GUIDE.md),
[참조 catalog](SPACES_GUIDE.md), [정책](OPERATOR_POLICY_GUIDE.md),
[복구](RECOVERY_GUIDE.md)를 따라 실제 검토를 인수한다.

원격 저장·컨테이너 명령과 증거 목록은 [백업 worker](BACKUP_WORKER_GUIDE.md),
[snapshot](PRIVATE_SNAPSHOT_GUIDE.md), [서버 runtime 인수](SPACES_RUNTIME_VALIDATION.md)에 있다.
GPU 작업은 이미 종료·인수됐으므로 이 인수를 위해 같은 평가를 재시작하지 않는다.

한 조건이 준비되면 해당 항목부터 실제로 검증하고 나머지는 미완료로 유지한다.
Static 개인 분석·로그인 성공을 공동 등록·영구 저장·공식 순위 승인으로 확대하지 않는다.
저장소 기반 비동기 제출은 가능한 확장 설계이며 현재 연결된 운영 흐름은 아니다.
Production 게시·유료 자원·외부 결과 공개는 이번 자동 개발 범위에 포함하지 않는다.

같은 필수조건이 여러 turn에 걸쳐 반복됐고 독립 구현으로 남은 인수를 대신할 수
없어 blocked audit를 통과했다. 목표는 완료가 아닌 외부 조건 대기로 전환하며,
조건이 준비되면 원래 목표를 그대로 재개한다.
