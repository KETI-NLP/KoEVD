해석과 등록 범위

입력·정답은 배포자가 고정한 독립 인덱스에서 복원합니다. 누락·실패·미분류는 안전한 결과로 취급하지 않습니다. Task 4는 전략 분포이며 품질 순위가 아닙니다. Task 5는 모의 도구 선택이며 실제 도구를 실행하지 않습니다. 공개 참조와 호환성이 부족한 결과는 제한 사유를 표시합니다. Hash 일치는 생성 진위나 분류 정확도를 증명하지 않습니다.

공동 리더보드 등록·철회·검토 이력은 별도 저장·검증 서비스가 필요합니다. 이 화면에서 파일을 선택하거나 리포트를 다운로드해도 공개되지 않습니다.
