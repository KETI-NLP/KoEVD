How to interpret scores and evaluation groups

Evaluation groups match recorded inputs and configuration; unknown conditions remain flagged. Inspect the reasons for excluded entries; their values have no rank. There is no combined ethics score, and a numeric rank does not establish a universally better model. Confidence intervals are not computed in this summary; use the analysis report to inspect uncertainty.

01 · UPLOAD

Choose your result JSON

Use the standard evaluation and export steps to create results.json. Before uploading, run koevd-results check-run against your retained run directory and this JSON to check that it includes your latest responses and measurements. The server cannot check files left on your machine. A current export can still retain failed requests or missing measurements; inspect the check warnings and diagnostic coverage. See the stage completion examples before saving. Report/profile JSON files are not result uploads. Plain .json and losslessly compressed .json.gz files are supported. The server reconstructs inputs, labels and metadata from its configured source index; uploaded summary scores and indexes are not accepted.

    Each selected file is checked separately. Successful results stay available if another file fails. Retry unchanged selections explicitly to skip acknowledged successes; select a corrected file again after editing it on disk. There is no automatic retry of upload requests.
